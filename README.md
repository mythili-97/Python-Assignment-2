# Python-Assignment-2
The assignment focuses on working withcore data structures such as lists,dictionaries,sets and conditional statements.
Data Structures-list,Dictionary,Set and Conditional Statements:
This assignment is designed for python learners to practice fundamental programming concepts using lists,sets,dictionaries and conditional statements.
Teh progrmans demonstrate how these core data structures can be created,accessed,modified and used in decision-making scenarios.

## Description
The main objectives of this assignment are to develop an understanding of:
*List creation,modification and access operations.
*Dictionary creation and manipulation using Key-value pairs.
*Set properties such as union,intersection.
Decision-making using if,elif,else statements.

Tools Used:
*Python
*Google Colab/Jupyter Notebook

Assignment Tasks:
Each Tasks include:
1.Pyhton Code
2.Execution of the program
3.Display of the output
4.Application of the relevant Python concept

Learning Outcome:
After completing this assignment I gained a better knowledge of Python's fundamental data structures and conditional statements.Teh exercise helped me to manipulating data using lists,sets,dictionaries while conditional statements improved my ability to implemnt logical-decision making in Python programs.
